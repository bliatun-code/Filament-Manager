# v0.35.0 product screenshots

The README and English guide use the English captures in this directory.
The Norwegian guide uses the separate Norwegian captures in `nb/`.

These are actual application captures from a private, de-identified library copy,
with real stock and an active ABS print. The printer overview shows actual MQTT
progress. Slots 2–4 use their confirmed inventory records; slot 1 stays unlinked
to illustrate the observed-roll workflow. Personal contacts and connection
settings are excluded. The source library is not distributed.

Only window chrome is cropped from native captures. Generic tablet and phone
frames surround the unmodified Companion viewports. No app content or printer
readings are generated for these screenshots.
