# Filament Manager v0.36.3

- Desktop LAN pairing checks the host's library before sending the pairing code. The client also checks the new address before reconnecting to a host that moves.
- Older active loans remain visible on paired clients, even when there are thousands of newer returned loans.
- Purchase receipts accept up to 100 rolls at a time. Retrying an unconfirmed receipt against an updated host returns the original result if it was already saved.
