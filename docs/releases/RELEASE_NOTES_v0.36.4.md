# Filament Manager v0.36.4

- In Companion, you can retry an unconfirmed purchase receipt after reloading, even if the order already shows as received. The retry uses the original quantity and purchase details.
- If an older host cannot accept purchase details, the desktop app lets you correct the draft and try again.
- Updated the app's SQLite binding and improved the database checks during Windows installation and upgrades.
