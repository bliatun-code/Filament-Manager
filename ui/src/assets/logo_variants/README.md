# Logo variants v3

These 10 icons are colorful filament spool concepts with **1–3 spools**.

- `logo-v3-01.svg` → 1 spool + filament tail
- `logo-v3-02.svg` → 1 spool angled + dual filament lines
- `logo-v3-03.svg` → 3 spools (row)
- `logo-v3-04.svg` → 2 overlapping spools
- `logo-v3-05.svg` → 3 spools (small-large-small)
- `logo-v3-06.svg` → 3 spools (staggered triangle)
- `logo-v3-07.svg` → 2 spools (vertical)
- `logo-v3-08.svg` → 3 spools (cluster)
- `logo-v3-09.svg` → 1 large + 1 mini spool
- `logo-v3-10.svg` → 3 spools (hero mix)

Each SVG contains both day and night color tokens through
`@media (prefers-color-scheme: dark)`, so it can auto-adapt to system theme.
